# 十二星座小太空

> 7 岁的小爱口述的睡前有声故事系列。

在很深很深的夜空里,有一个地方叫「十二星座小太空」。十二星座姐妹和特别星座们——爸比座、妈咪座,大海星座的汐涟座、夕海座,草原星座的星砾座、青原座,还有月亮姐姐、月亮妹妹和星星姐妹们——一起住在星星中间。

目前已上线七集。第一集《想家的大海》:双鱼座和水瓶座想念家乡的大海,最后在星空泳池找到了家的感觉。

## 站点

Astro 静态站,部署在 Cloudflare Pages:https://zodiac-little-space.jiangle.name/

```bash
cd site
npm install
npm run dev      # 本地开发(predev 自动同步资源)
npm run build    # 构建到 site/dist/
```

仓库约定见 [AGENTS.md](./AGENTS.md),世界观与角色设定见 [docs/系列设定.md](./docs/系列设定.md)。
